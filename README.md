# TSS Acharya - Official Website

This is the official website for **TSS Acharya**, a highly rated CBSE & ICSE coaching institute located in the Katra area of Prayagraj, Uttar Pradesh.

## About TSS Acharya

TSS Acharya stands out for its modern, air-conditioned classrooms equipped with smartboards, and a highly supportive faculty—including popular mentors like Ankit Sir—who focus on building strong concepts in Science and Mathematics for students from Class 6 to Class 12.

## Tech Stack

This is a [Next.js](https://nextjs.org) project built with:
- **Next.js 15** - React Framework
- **TypeScript** - Type Safety
- **Tailwind CSS** - Styling
- **Lucide Icons** - Icon Library

## Getting Started

First, install dependencies:

```bash
npm install
```

Then, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
